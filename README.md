# Groupsum GitHub Profile

This repository owns the public organization profile shown at [github.com/groupsum](https://github.com/groupsum).

The profile content lives in [profile/README.md](profile/README.md). It summarizes Groupsum's public repositories, links directly to the active project surfaces, and keeps the organization description grounded in current public repo truth.

## Public Repository Coverage

- [groupsum/ssot-registry](https://github.com/groupsum/ssot-registry): repository-native single source of truth for features, claims, tests, evidence, ADRs, specs, boundaries, and releases.
- [groupsum/markdown_workspace](https://github.com/groupsum/markdown_workspace): MdWrk multi-package workspace for markdown apps, native shells, extension contracts, distribution tooling, governance checks, and release automation.
